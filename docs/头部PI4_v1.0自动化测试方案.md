# 头部 PI4 v1.0 自动化测试方案

## P1：安全与运动

- 覆盖上/下电、上电状态、使能、校准、角度、单/四关节运动、运动/到位状态、错误/清错、碰撞阈值和急停。
- 运动使用现场确认的 `[0, 0, 0, 0]` 与速度 `10`；角度容差 `0.1°`，等待超时 `10s`。
- 运动需 `--run-hardware --run-motion --run-manual`；校准、急停、使能、上/下电与碰撞阈值另需 `--run-danger`。急停按下、松开和校准结果由弹窗人工确认。

## P2 / P3：常规与诊断

- P2：运行速度、电流、温度、LED、屏幕动画。
- P3：主/修订版本、Debug 状态读写、固件升级非法参数。
- 不包含通信中断、100 次稳定性和真实固件升级；动画数据未在 Excel 提供时跳过。

## 参数与恢复

- 连接：`--head-ip`、`--head-port`，默认 `192.168.0.231:6501`；必须加 `--connect-head`。
- 数据册：`test_data/head.xlsx`，每个接口一个 sheet，字段包含输入、期望、恢复参数、超时与容差。
- 文件组织：每个接口对应一个 `test_<api>.py`；急停保护为独立专项文件。禁止按“只读/配置/显示”等功能域聚合多个 API。
- 可读 setter 均执行“读原值、写入、回读、finally 恢复、再读回”。使能与 LED 无读取接口，必须由 Excel 提供恢复参数；校准不自动恢复。
- 当前 SDK 若只支持 2 关节，J3/J4 与四关节结构断言记为 `xfail`，等待兼容 4 关节的 SDK 后自动执行。

## 测试方法与命令

- 方法：等价类、边界、场景、状态迁移、错误推断、接口一致性。
- 收集：`pytest testcases/head --collect-only -q`。
- 常规真机：`pytest testcases/head --run-hardware --connect-head -q`。
- 运动：额外加 `--run-motion --run-manual`；高风险：额外加 `--run-danger`。
